{# The Jinja half of the icon story. Emits a reference into the sprite and carries NO path data — `_icon_sprite.html` is the only place a drawing lives, so the Jinja side and the JavaScript side cannot come to disagree about what an icon looks like. Usage: {% import "_icons.html" as icons %} Autoescape is on (Starlette sets it), and a macro returns Markup — so this needs no `|safe` at the call site. Adding one would be unnecessary and would teach the habit. `aria-hidden` is unconditional: every icon in this app sits beside its own words or inside a control that already carries a title. See the sprite's own notes. #} {% macro icon(name) -%} {%- endmacro %}
