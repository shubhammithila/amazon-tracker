{# Purchase rate, HSN code and GST rate per product. Administrators only. Asked for: "lets add a products tab separately where I can update the pricing. Jitne products ka pricing hai abhi wo daal do. and rest ka blank chor do." Four things about this page are deliberate: 1. **Unpriced products sort FIRST.** The screen exists to fill blanks, so it opens on them. Sorting alphabetically would bury four missing prices among 267 correct ones, which is how a shipment gets refused at the last moment. 2. **A blank price is not zero.** Amazon rejects an inbound shipment whose declared value is 0 — and does it with "We encountered an internal error. Please try again.", which reads like a fault on their side. So the field is left empty and the server refuses a 0, rather than storing one. 3. **Every row saves on its own.** No global Save that could half-apply across 271 rows, and a failed save says which product failed rather than reporting success. 4. **HSN defaults to 1106 at 5%** because every F2D product is, but both are editable: a non-food line would be classified differently, and a wrong HSN on a GST document is worse than a blank one. #}
